Cheat sheet

Every day

git status
What changed? Run it before every other command.
git add .
Stage all changes (check status first so .env never sneaks in).
git commit -m "Add signup form"
Save a snapshot. Say what changed, in present tense.
git pull
Get teammates' work before you start.
git push
Send your commits to GitHub.

Branches

git switch -c feature/signup
Create a branch and move onto it. One branch per feature.
git switch main
Go back to main.
git merge feature/signup
Bring that branch into the one you are on.
git branch -d feature/signup
Delete a branch after it is merged.
git log --oneline --graph --all
Draw this page's graph in your own terminal.

Fixing a conflict

1. Open the file
Find the <<<<<<< / ======= / >>>>>>> block.
2. Choose the final code
Keep one side, the other, or combine. Delete all three marker lines.
3. git add <file>
Tells Git "this file is resolved".
4. git commit
Completes the merge. Then run the app and test before you push.

Panic buttons

git merge --abort
Cancel a messy merge and go back to before you started.
git restore <file>
Throw away unsaved edits to one file.
git restore --staged <file>
Unstage a file you added by mistake (like .env).
git stash / git stash pop
Park unfinished work, pull, then bring it back.
! [rejected] … fetch first
Your push was refused because GitHub has newer commits. Run git pull, fix any conflict, then push again.
